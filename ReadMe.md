# Gap
This is a simple pomodoro timer, with settings and notifications  
Please note that this project is still WIP, so some of the described features are not ready yet :(

## Features
* 🍅 Simple pomodoro functionality
* 🔔 Notifications
* 📊 Statistics
* ⚙️ Settings
* 🔮 Undocumented debug feature
